# Алгоритм Полларда «ро»

Вероятностный алгоритм **факторизации** целых чисел. Предложен Джоном Поллардом в 1975 году. Ищет **нетривиальный делитель** составного числа `n`.

## Сложность

`O(n^(1/4))` в среднем |

Для сравнения: перебор делителей — `O(√n) = O(n^(1/2))`.

## Пример: `n = 8051`

`f(x) = x^2 + 1`, `x0 = 2`:

| i | x | y | \|x−y\| | gcd |
|---|---|-----|---------|-----|
| 1 | 5 | 26 | 21 | 1 |
| 2 | 26 | 7475 | 7449 | 1 |
| 3 | 677 | 594 | 83 | **83** ✅ |

Результат: `8051 = 83 × 97`.

## Особенности

- **Вероятностный** — может не найти делитель с первого раза.
- **Срыв** (`gcd = n`) — лечится сменой `c`.
- **Плохо работает** на простых числах и на `n = p^2`.
- **Хорош** для чисел с маленьким делителем.

## Применение

- Криптоанализ RSA
- Системы компьютерной алгебры (SymPy, PARI/GP)
- Project Euler
- Тестирование простоты (быстрый поиск делителя)
